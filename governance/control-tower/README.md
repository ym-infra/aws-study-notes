# AWS Control Tower
 
## Control Towerとは
 
マルチアカウント環境を「ルール付き」で楽に管理するための仕組み。
 
AWSでは、環境や用途ごとにアカウントを分けるマルチアカウント運用が基本。
ただ、アカウントが増えるほど設定の抜けやバラつきが出やすく、手作業での管理は大変になる。
Control Towerを使うと、ルールを決めたマルチアカウント環境をまとめて整えられる。
 
## 何ができるのか
 
- マルチアカウント環境の土台（OUやログ用・監査用のアカウント）をまとめて作れる
- OU単位でルール（コントロール）を効かせて、違反を禁止・検知できる
- ルール適用済みのアカウントを、決まった手順で追加できる
